# Historia de datos — De las citas a las decisiones

**Pregunta de negocio:** ¿Qué nos dicen las citas de 2025 sobre las inasistencias veterinarias?

**Punto de partida:** se depuraron 1.512 registros originales, eliminando 12 duplicados. La base final contiene 1.500 citas.

**Panorama general:** 1.017 atendidas, 189 no asistidas, 172 canceladas anticipadamente y 122 reprogramadas. El total cuadra: 1.500.

**Indicador central:** 189 / (1.017 + 189) = 15,67 % de inasistencia entre citas elegibles.

**¿Dónde se concentran las ausencias?** Consulta general: 77; vacunación: 45; control preventivo: 30; desparasitación: 22; seguimiento clínico: 15. Consulta general reúne 40,74 % de las ausencias; esta proporción no es una tasa de inasistencia del servicio.

**¿Qué hacer?** Evaluar recordatorios y confirmaciones, revisar la tendencia mensualmente y medir el efecto de las acciones antes de atribuirles mejoras.

**Evidencia visual pendiente:** insertar capturas reales del tablero, su modelo estrella y sus filtros; no se incluyen gráficos simulados como evidencia de Power BI.
