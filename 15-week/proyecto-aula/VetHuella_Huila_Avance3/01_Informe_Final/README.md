# 01 — Informe Final

## Proyecto VetHuella Huila

**Asignatura:** Inteligencia de Negocios  
**Periodo académico:** 2026-B  
**Fase:** Avance 3 — Análisis de resultados y recomendaciones

## Descripción

Esta carpeta contiene el informe final del proyecto académico VetHuella Huila, orientado al análisis de las inasistencias a citas veterinarias durante el año 2025 mediante herramientas de inteligencia de negocios.

El documento integra las etapas desarrolladas durante el proyecto:

1. Definición de la problemática de negocio.
2. Preparación y limpieza de datos mediante Power Query.
3. Construcción del modelo dimensional tipo estrella.
4. Implementación de indicadores mediante DAX.
5. Desarrollo de un dashboard interactivo en Power BI.
6. Interpretación de resultados y recomendaciones de negocio.
