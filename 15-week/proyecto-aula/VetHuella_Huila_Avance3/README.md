# VetHuella Huila — Avance 3

## Inteligencia de Negocios 2026-B

**Proyecto:** Análisis de inasistencia a citas veterinarias durante 2025.

**Herramienta principal:** Microsoft Power BI.

### Objetivo

Analizar los resultados del dashboard de VetHuella Huila para identificar patrones de inasistencia a citas veterinarias y formular recomendaciones que permitan mejorar la gestión de los servicios.

### Metodología

1. Definición del problema de negocio.
2. Extracción, transformación y limpieza de datos mediante Power Query.
3. Construcción del modelo estrella y medidas DAX.
4. Desarrollo del dashboard interactivo en Power BI.
5. Interpretación de resultados y recomendaciones de negocio.

### Resultados principales

- Registros originales: 1.512.
- Registros duplicados eliminados: 12.
- Total de citas analizadas: 1.500.
- Citas atendidas: 1.017.
- Citas no asistidas: 189.
- Citas canceladas anticipadamente: 172.
- Citas reprogramadas: 122.
- Tasa de inasistencia: 15,67 %.

### Hallazgo principal

El servicio de consulta general registró 77 inasistencias, lo que representa aproximadamente el 40,74 % del total de citas no asistidas.

### Recomendaciones

Se propone implementar recordatorios anticipados, facilitar la confirmación y cancelación de citas y monitorear periódicamente los indicadores mediante Power BI.

### Entregables

- Informe final.
- Historia de datos.
- Recomendaciones de negocio.
- Evidencias del dashboard.
- Guion de sustentación.

**Nota:** Proyecto académico desarrollado con datos sintéticos.
